Hermes Calendar

A personal Google integration being configured for its owner's use.

Intended functionality

  • Read available Google Calendar events and create or edit events only on an explicitly approved calendar, at the owner's request.
  • Read Gmail messages without sending, deleting, archiving or marking messages read.
  • Read the owner's Google Classroom courses, coursework, grades, announcements and materials without submitting or modifying them.

Setup status

Account connections and write restrictions are still being configured. This informational website does not provide public access to Google accounts.

A privacy policy will be added before production authorization setup is completed.
